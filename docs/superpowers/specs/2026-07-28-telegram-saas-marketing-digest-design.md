# Telegram-дайджест по SaaS-маркетингу с минимальным бюджетом — дизайн

Дата: 2026-07-28

## Цель

Автоматический бот, публикующий в Telegram-канал на русском языке дайджест
свежих постов от 7 отобранных экспертов по SaaS-маркетингу/росту, а также,
при отсутствии свежего контента у них, — истории бутстрап-фаундеров,
построивших SaaS с нулевым/околонулевым бюджетом на маркетинг. Контекст
пользователя: он создаёт SaaS-продукты через вайбкодинг и продвигает их с
околонулевыми вложениями — дайджест должен помогать именно в этом.

Перед запуском регулярных дайджестов в канал публикуется один разовый пост
с "вечными" принципами SaaS-маркетинга, собранными из архивов блогов этих
же 7 авторов — то, что не устаревает со временем.

### Резервный пул (бутстрап-истории с $0/минимальным маркетинговым бюджетом)

Используется, когда ни у одного из основных 7 нет нового поста с прошлой
проверки (ожидается — большинство запусков). Кандидаты: Indie Hackers
(интервью/milestones), Starter Story, Failory, блоги соло/AI-фаундеров
(Marc Lou, Tony Dinh, Damon Chen, Daniel Vassallo). Точный список фидов
подбирается и валидируется на этапе реализации.

## Архитектура

```
GitHub Actions (cron, 3×/день: 09:00, 15:00, 21:00 Europe/Kyiv)
   │
   ├─ 1. Fetch — читает RSS всех основных 7 источников
   ├─ 2. Diff — сравнивает GUID/ссылки с state.json в репозитории,
   │           отбирает то, что ещё не публиковалось
   ├─ 3. Если есть новое → фильтр релевантности (см. ниже)
   │    Если релевантного нет → берёт 1 неопубликованную историю
   │    из резервного пула
   ├─ 4. Суммаризация на русском через Gemini API (бесплатный тариф)
   ├─ 5. Публикация в Telegram-канал (Bot API sendMessage)
   └─ 6. Коммит обновлённого state.json обратно в репозиторий
```

Состояние (какие посты/истории уже отправлены) хранится в JSON-файле в
самом репозитории — отдельная БД не нужна. Job коммитит файл в конце
своего запуска.

## Фильтр релевантности

Полный текст поста передаётся в Gemini с инструкцией оценить релевантность
теме "маркетинг SaaS с минимальным/нулевым бюджетом" (рост, привлечение,
retention, позиционирование, дистрибуция, GTM, продуктовый маркетинг).
Нерелевантные посты (например, чисто про фандрайзинг, найм, HR) пропускаются
без публикации.

## Формат сообщения

Каждый релевантный пост в дайджесте:

```
🔹 [Автор] — [Заголовок оригинала]

[TL;DR: 2–4 предложения — суть поста]

💡 Практический вывод: [конкретное действие/инсайт, применимое
   при нулевом бюджете]

🔗 [ссылка на оригинал]
```

Несколько релевантных постов за одну проверку — одно сообщение списком.
Материал из резервного пула — тот же формат, с пометкой, что это
резервный источник.

Если за проверку не найдено вообще ничего (ни у основных, ни в резервном
пуле) — сообщение не отправляется, скрипт молча завершается.

## Начальный пост про "вечные" принципы

Разовая задача, выполняется до включения крона: ресёрч по архивам
блогов/твиттеров основных 7 авторов, сборка поста на русском о принципах
маркетинга, не зависящих от времени (позиционирование через нишу, building
in public, органический контент-маркетинг, PLG-механики, word-of-mouth
дизайн продукта и т.п.), с атрибуцией авторам. Публикуется в канал первым
сообщением.

## Технологический стек

- **Хостинг/расписание**: GitHub Actions (cron), бесплатно
- **LLM для суммаризации**: Google Gemini API, бесплатный тариф
- **Доставка**: Telegram Bot API
- **Хранилище состояния**: JSON-файл в репозитории
- **Язык реализации**: Python 3 (`feedparser` для RSS, `requests` для
  HTTP-вызовов к Gemini и Telegram Bot API — без тяжёлых зависимостей,
  быстрый холодный старт в GitHub Actions)

## Что нужно от пользователя перед реализацией

- Токен Telegram-бота (через @BotFather)
- Канал/группа с ботом в роли админа (username или chat_id)
- Ключ Google Gemini API (aistudio.google.com, бесплатно)
- Подтверждение нового GitHub-репозитория для проекта

Секреты хранятся в GitHub Actions Secrets, не в коде.
